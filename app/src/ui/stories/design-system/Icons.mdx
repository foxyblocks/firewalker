# Icons

Five line icons, drawn on a 24-unit grid with a 1.7 stroke, round caps, and the current text color. They sit beside a visible label and are hidden from screen readers, so the label carries the meaning.

<IconGallery />

## Rules

- An icon goes beside words, not instead of them. Icon-only buttons, such as a pose's clear button, need a label that names the action and the thing: "Clear heel down".
- Draw new icons on the same grid with the same stroke, and add them to `Icon.tsx` so they appear here.
- The Studio mockups add icons for Lights and Sound tabs. They'd join this set on the same grid.
